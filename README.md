# 量子乱数席ぎめツール by IBM Quantum, Qiskit, and IBM Bob

IBM Quantumの実機で事前に取得した量子乱数を使って、受付で来場者の席を1人ずつ決める、飲み会などの席決めアプリケーションです。

## ✨ 特徴

- **実機の量子乱数**: IBM Quantumの実機（Heron r2）で事前に取得した乱数マップを、受付時に読み出して使用（受付中にIBM Quantumへ接続しない）
- **IBM Quantum風のダークUI**: Carbonデザインを参考にしたダークテーマ
- **自由な机の描画**: 四角・丸（楕円）・多角形をドラッグ／クリックで描画
- **受付型**: 来場者が来るたびに空席から1席を決定。取消・全体の配置換え・CSV出力に対応
- **参加者リスト**: 受付画面から名前の候補を上書き保存でき、候補をタップして選んだあとも書き換え可能。リストにない名前は受付でそのまま入力できる

## 🚀 セットアップ

### 1. 必要な環境

- Python 3.10以上（OpenSSL版。macOS付属のPython 3.9はLibreSSLのためIBM Cloudへ接続できません。例: `brew install python@3.12`）
- IBM Quantum Platform アカウント（乱数マップの取得時のみ使用）

### 2. IBM Quantum APIトークンの取得

1. [IBM Quantum Platform](https://quantum.cloud.ibm.com/) にアクセス
2. アカウントを作成またはログイン
3. 右上のアカウントアイコンから「Account settings」を選択
4. 「API token」セクションでトークンをコピー

### 3. インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd quantum_seat

# 仮想環境を作成（推奨）
python3.12 -m venv venv

# 仮想環境を有効化
# macOS/Linux:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# 依存パッケージをインストール
pip install -r requirements.txt
```

### 4. 環境変数の設定

```bash
# .envファイルを作成
cp .env.example .env

# .envファイルを編集してIBM Quantum APIトークンを設定
# IBM_QUANTUM_TOKEN=your_actual_token_here
```

### 5. 量子乱数（乱数マップ）を実機から取得（イベントの前に）

```bash
python fetch_quantum_pool.py
```

待ち行列が最も短い実機を自動選択し、100マップ（100量子ビット × 100ショット = 10,000ビット）を1ジョブで取得して `data/random_pool.json` に追加します（所要時間は数分程度）。受付はこのファイルから順に読み出します（読んだビットは再利用しません）。

- 受付1人あたり十数ビット、全体の配置換えも同程度を消費するので、10,000ビットで数十人規模のイベントを複数回まかなえます
- 画面右上のカードに残りビット数が表示され、残りが少なくなると警告します。足りなくなったら再度実行すると追加されます
- `--maps` / `--qubits` / `--backend ibm_fez` で取得量や実機を指定できます
- 取得したビットの偏りは `python verify_randomness.py` で確認できます（プールは消費しません）

### 6. アプリケーションの起動

```bash
python app.py
```

ブラウザで `http://127.0.0.1:5001` にアクセスしてください（ポートは環境変数 `FLASK_PORT` で変更できます）。

## 📖 使い方

来場者が1名ずつ来る会（飲み会など）向けの「受付型」です。受付のたびに量子乱数で空席から席を決めます。

### 1. 会場レイアウトを設定（事前）

「会場レイアウト」タブで会場を作ります。変更は自動保存されます。

- **○ 丸テーブル / □ 四角テーブル**: ツールを選んでキャンバスをクリックするとテーブルを配置
- **● 席を置く**: 席のある場所をクリックして配置（席番号は自動採番）
- **選択・移動**: ドラッグで移動、クリックで選択
- **机を大きく／小さく**: 選択中のテーブルのサイズ変更
- **選択を削除**（Deleteキー）: 選択中のテーブル・席を削除（着席中の席は削除不可）

### 2. 受付

「受付」タブで名前を入力し、「量子乱数で席を決める」を押すと、空席の中から1席が決まります。

- ボタンには、そのときの空席数から見積もった**消費ビット数の目安**（例: 「量子乱数で席を決める（約4ビット消費）」）が表示されます。棄却サンプリングのため実際の消費は前後します（実際の消費ビット数は結果に表示されます）。画面右上のカードの残りビット数は、受付・配置換えの演出に合わせてカウントダウンします
- 受付ボタンを押すと、約3.5秒のビンゴ風の演出が流れます（空席が重ね合わさった状態 → 1席に「収縮」）。演出中に画面をクリックするとスキップでき、OSの「視差効果を減らす」設定がオンの場合や空席が1つだけの場合は省略されます。**演出は見せ方だけの効果で、席は押した時点で乱数プールから決まっています**
- 決まった席は大きく表示され、会場図で強調表示されます
- 「参加者リスト（名前の候補）」は受付画面に常時表示されています。1行1名で入力し、「この内容で上書き保存」を押すと、名前の候補になります（`data/state.json` に保存。前回の名前は残りません）。候補をタップすると名前欄に入り、書き換えてから受付できます。リストにない人は名前をそのまま入力してください。着席済みの人は候補から消えます
- 着席一覧の「取消」で、受付ミスの訂正ができます

### 3. 全体の配置換え・リセット

- **全体の配置換え**: 着席済みの全員の席を、全座席（空席を含む）から量子乱数で決め直します
  - 押すと約10秒の全画面演出が流れます（全員が光の玉になって渦を巻き、観測で1人ずつ新しい席へ着地 → 花火）。クリックでスキップでき、「視差効果を減らす」設定では省略されます。席は押した時点で決まっており、演出は見せ方だけの効果です
- **全体リセット**: 着席状況をすべてクリアします（会場レイアウトは残ります）
- **CSV出力**: 席番号・名前・受付時刻をダウンロード

### データの保存

レイアウトと着席状況は `data/state.json` に保存されるため、サーバーを再起動しても残ります（`.gitignore` 済み）。保存先は環境変数 `STATE_FILE` で変更できます。

**乱数について**

- 受付・配置換えはプールからの読み出しだけなので、IBM Quantumの待ち時間は発生せず一瞬で決まります
- プールが空になった場合は疑似乱数にフォールバックし、画面に警告を表示します（結果カードにも「疑似乱数」と表示）
- サーバーは `127.0.0.1` のみで待ち受けます。デバッグモードは `FLASK_DEBUG=1` のときだけ有効です

## 🧪 量子乱数の仕組み

アプリ内の「仕組み」タブ（`/about`）に、実行した量子回路の図・席の決め方・品質の限界を図入りでまとめています（取得データの個別情報は載せていません）。要点は以下のとおりです。

1. **取得（事前）**: `fetch_quantum_pool.py` が、全量子ビットにアダマールゲート（H）をかけて測定する回路を `SamplerV2` で実機に投入します。1ショット = 1つの乱数マップ（量子ビット数ぶんのビット列）で、ショット順に連結して `data/random_pool.json` に保存します
2. **読み出し（受付時）**: 空席数 n に対し、必要なビット数（`ceil(log2 n)`）だけ未使用ビットを読み、n 以上の値なら読み捨てて引き直します（棄却サンプリング。剰余を使わないため一様）
3. **配置換え**: 着席者ごとに1席ずつ、同じ方法で空席から決めます

実機の読み出し誤差により、生ビットに1%程度の偏りが出ることがあります（`verify_randomness.py` で確認可）。席決めへの影響は小さいですが、気になる場合は `--maps` を増やして取得し直してください。

### 使える実機について

`fetch_quantum_pool.py` は、アカウント（インスタンス）で利用できる実機から待ち行列が最も短いものを選びます。日本国内の実機を使うには、そのマシンを利用できるインスタンスのCRNを `.env` の `IBM_QUANTUM_INSTANCE` に設定してください。

## 🔐 セキュリティ

- IBM Quantum APIトークンは環境変数（`.env`）で管理し、取得スクリプトだけが使用します（アプリ本体はトークン不要）
- `.gitignore`で `.env`・`data/`（乱数プール・着席状況）を除外。乱数プールは本人のみ読み書きできる権限（600）で保存します

## 🐛 トラブルシューティング

詳細なトラブルシューティングガイドは [TROUBLESHOOTING.md](TROUBLESHOOTING.md) を参照してください。

### よくある問題

#### ポート5000が使用中

アプリケーションはデフォルトでポート5001を使用します：

```bash
python app.py
# ブラウザで http://localhost:5001 にアクセス
```

macOSでポート5000がAirPlayで使用されている場合は、システム設定でAirPlay Receiverを無効化するか、別のポートを使用してください。

#### 取得スクリプトが接続エラー（SSLError）になる

macOS付属のPython 3.9（LibreSSL）ではIBM Cloudへ接続できません。OpenSSL版のPython 3.10以上で仮想環境を作り直してください（`brew install python@3.12` → `python3.12 -m venv venv`）。

### 「乱数プールが空です」と表示される

`python fetch_quantum_pool.py` で実機から乱数を取得してください。それまでは疑似乱数で動作します。

### パッケージのインストールエラー

**症状**: `pip install`でエラーが発生

**解決方法**:

```bash
# pipをアップグレード
pip install --upgrade pip

# 個別にインストール
pip install qiskit
pip install qiskit-ibm-runtime
pip install flask
```

## 📝 設定

### .env

- `IBM_QUANTUM_TOKEN`: IBM Quantum APIトークン（`fetch_quantum_pool.py`で必須）
- `IBM_QUANTUM_INSTANCE`: IBM Cloud CRN（推奨）
- `IBM_QUANTUM_BACKEND`: 使う実機名（例: `ibm_fez`）。空なら待ち行列が最短の実機を自動選択
- `POOL_FILE` / `STATE_FILE`: 乱数プール・着席状況の保存先（既定: `data/random_pool.json` / `data/state.json`）
- `FLASK_PORT`（既定5001）/ `FLASK_DEBUG=1`（デバッグ有効）
